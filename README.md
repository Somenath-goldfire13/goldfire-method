### What is Goldfire?
My method to explore Goldbach's Conjecture: Every even N > 2 = P + Q where P,Q are primes.

### Example: N=30
30 = 7+23, 11+19, 13+17
G(30)=3 pairs

### Formula
Q = N - P
If Q is prime, we found a pair.
